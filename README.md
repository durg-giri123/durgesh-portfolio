## 🚀 Quick Local Preview

You can open and preview the website instantly using any of these methods:

### Method 1: Python Local Server (Recommended)
```bash
cd portfolio
python -m http.server 3000
```
Then open [http://localhost:3000](http://localhost:3000) in your web browser.

### Method 2: Node / NPX
```bash
cd portfolio
npx serve .
```

### Method 3: Direct File Open
Simply double-click `index.html` in file explorer to open it in Chrome, Edge, or Brave.

## 🚢 Deployment in 1 Minute

### Deploy to GitHub Pages:
1. Create a repository on GitHub (e.g. `durgesh-portfolio` or `durg-giri123.github.io`).
2. Push the contents of the `portfolio` directory:
   ```bash
   cd portfolio
   git init
   git branch -M main
   git remote add origin https://github.com/durg-giri123/durgesh-portfolio.git
   git add .
   git commit -m "feat: initial authentic portfolio release"
   git push -u origin main
   ```
3. In repository settings on GitHub, navigate to **Pages** -> Set Source to **Deploy from a branch (`main` / root)** -> Click **Save**.

### Deploy to Vercel / Netlify:
- **Netlify**: Go to [app.netlify.com/drop](https://app.netlify.com/drop) and drag the `portfolio` folder directly into the browser!
- **Vercel**: Import the GitHub repository on [vercel.com](https://vercel.com) with framework set to `Other` and root directory as `portfolio`.
